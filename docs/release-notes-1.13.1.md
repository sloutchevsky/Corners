# Flashborn 1.13.1

Tab hover now uses only the animated thumbnail inside the sidebar. The floating preview box has been removed. In light mode, an unselected hovered tab uses the selected tab's light grey at 50% opacity; dark mode keeps its existing appearance.

Dragging now uses pointer capture within Flashborn for tabs, Flash library cards, bookmarks and downloads. Drag by a title, thumbnail or card background; a straight line marks the destination and lists scroll at their edges. A completed drag saves the new order without opening the card or changing the selected tab. Ordinary clicks and keyboard reordering remain available.

The repair was checked with real Windows mouse drags in all four collections, including a Flash tab during playback. Installer configuration, Adobe player binaries and external file-drop handling are preserved. This release does not claim to resolve the previously noted intermittent Flash tab-switch layering issue.
