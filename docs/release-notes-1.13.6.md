# Flashborn 1.13.6

The browser-menu dots rotate 90 degrees and extend into three horizontal lines with round ends. The lines form a square and remain visible while the menu is open. Moving away from the closed button or dismissing the menu outside reverses the animation.

Open and download Save As dialogs share the last selected directory across browser restarts. This includes HTML sources, library images and extension folders. Canceling a dialog preserves the remembered location; removed folders fall back to the dialog's default.

Normal and Flashcognito new-tab search fields are pills with semicircular ends concentric with the round Go button. Small footnote locks align vertically with the first text line.

Validation: all 63 unit tests passed. The packaged application passed feature checks in both themes and window widths, folder-memory checks across restart, and the existing menu regression checks over normal and native Flash tabs. All 62 packaged source files match the working sources, and the native helper contents and pinned Adobe player bytes were verified.
