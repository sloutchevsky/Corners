# Animation experiments

These previews document work on the gold lightning bolt, lighting, and a proposed
serif-shaped bolt. They are development artifacts and are not loaded by the app.

The serif direction was deferred. Flashborn 1.7.3 ships the simple bolt implemented
in `src/ui/lightning.js`, with the static first frame generated by
`scripts/create-icon.js`.

Preview HTML can be opened directly in a browser. Inspection and build scripts
use the project's Node.js dependencies. PNGs record earlier visual iterations.
