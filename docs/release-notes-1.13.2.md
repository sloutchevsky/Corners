# Flashborn 1.13.2

Open tabs keep their thumbnails between browser sessions. Regular tabs save their last captured picture in a bounded local cache, including Adobe Flash frames. Restored background tabs show that picture immediately, without loading or waking the page. Duplicate tabs keep separate images. Flashcognito thumbnails remain in memory only; closed or navigated tabs lose their saved images.

Collapsing or expanding the sidebar now keeps tab rows, letters and icons in the same positions. Both states use 40 px rows, fixed icon anchors and matching header spacing, including short windows and scrolled lists. The selected tab's letter is bold in both themes, with its existing color. Inline thumbnail animations, pointer reordering and the installer configuration are preserved.
