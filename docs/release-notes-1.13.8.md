# Flashborn 1.13.8

Opening a special page now clears the previous website address and shows the same search placeholder as New Tab. Switching pages also clears a focused address draft and stale autocomplete state. Returning to a website tab restores its URL, while ordinary state updates preserve text you are actively typing.

Special-page titles are 30% larger. Flash Library uses consistent capitalization in the sidebar, menu and page heading. Its Library folder button and the portfolio title above the cards have been removed; the subtitle remains editable and existing collection metadata is preserved.

Validation: all 65 unit tests passed. The packaged application's special-page runtime check covers regular and Flashcognito addresses, focused drafts, returning to tabs, heading sizes, subtitle editing and Library layouts in both themes at wide and narrow window sizes. All 62 packaged source files, native helper contents and pinned Adobe player bytes were verified.
