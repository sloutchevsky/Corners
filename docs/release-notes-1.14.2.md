# Flashborn 1.14.2

The lower sidebar has one highlight that slides vertically between buttons on hover. Clicking selects a page; moving the pointer away returns the highlight to that page. The divider between Downloads and Settings is removed.

A subtle fade above the lower buttons blends from the sidebar's grey to transparent, in both light and dark themes. The highlight stays aligned when the sidebar collapses and skips animation when reduced motion is enabled.
